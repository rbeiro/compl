# CompI — instrucciones persistentes

Proyecto: CompI · Hotel Arts, migración de alojamiento a Cloudflare.
No rediseñar ni alterar funciones, marca, roles, datos o permisos durante la migración.
Trabajar en este repositorio privado; conservar la web antigua y Supabase en producción.
No ejecutar SQL, cambiar DNS ni publicar cambios de backend fuera del paso correspondiente.
No exponer credenciales, variables privadas o datos de usuarios; no copiar secretos al chat ni a Git.
Antes de modificar código: verificar `git status`, realizar el cambio mínimo y ejecutar pruebas relevantes.
No leer todo el proyecto ni mostrar archivos extensos: localizar primero rutas concretas, usar salida corta.
No invocar skills, MCP, subagentes o navegador salvo necesidad específica.
Reportar únicamente resultado, pruebas, bloqueo real y siguiente paso.

Para la migración, leer **solo cuando la tarea lo requiera**: `docs/HANDOVER_CLOUDFLARE.md`.
Estado más detallado: `ESTADO_PUBLICACION.md`. Procedimientos técnicos: `README.md`.
